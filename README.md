# English Training (speaking2)

AIを活用した英語スピーキング・トレーニング・アプリケーションです。

## 主な機能
- **AI会話生成**: シチュエーションに応じた英会話の練習。
- **リアルタイム添削**: 入力した英文に対する詳細な添削と解説。
- **表現の提案**: より自然な表現や、異なるトーン（フォーマル、カジュアル、シンプル）での言い換えを提案。
- **英訳練習モード**: 表示された日本語を英語に訳す練習機能。
- **Q&A機能**: システムの英文や添削内容についてAIに直接質問が可能。
- **音声読み上げ**: 高品質なニューラル音声による読み上げ（速度調整可能）。
- **発音練習（発音評価）**: 各例文に対して自分の声をマイクで録音し、Azure Speech Serviceの「発音評価 (Pronunciation Assessment)」APIを用いて発音を詳細に判定。総合スコアに加え、「正確性」「流暢さ」「完全性」の細部指標や、単語ごとの発音ミス・発音漏れを視覚的にフィードバックします。
- **ペルソナリアクション**: 3つの理解レベル（初級、中級、ネイティブ）のペルソナによる多角的なフィードバック。

- **会員システム**: メールアドレスとパスワードによるアカウント管理。ログイン状態の永続化（Remember-Me機能）により、iOS PWA等のアプリ再起動時でも自動ログインが行われ、デバイスを跨いだ学習データの同期が可能です。
- **画面状態の自動維持（PWA対応）**: 添削結果や回答、各メッセージごとのQ&Aチャット履歴、バリエーション展開状態などの全画面状態をリアルタイムで保存（`localStorage`）。数時間放置してPWAがメモリ解放・コールドスタートした場合でも、前回の学習状態をそのまま100%復元し、維持します。
- **URLから作成**: 指定したURLのウェブページから本文テキストを抽出し、設定された文字数に近いキリの良い部分を一字一句違わずに抜き出して英会話のお題とするモード。要約や余計な創作、アレンジを行わずに、Web上の実際の文章を使ってスピーキングの練習を開始できます。

### 復習ブックマーク時のQ&A履歴保存機能の追加
- 会話アイテムを復習に保存（ブックマーク）する際、そのアイテムに対して行った**Q&A（AIへの質問）の履歴も一緒に保存**されるようになりました。
- 復習セクションでアイテムを開いた際、過去にどのような質問をしてどのような回答を得たかをいつでも確認でき、より深い学習が可能になります。
- 復習モード中に新しく行った質問も、自動的に保存済みのデータに追記されます。

### 復習機能（Review Mode）の実装
- **練習/復習モードの切り替え**: ページ上部に「練習」と「復習」を切り替えるタブを設置しました。
- **お気に入り保存機能**: 各会話アイテムに保存ボタンを追加しました。気になったフレーズや練習した内容を「復習」セクションに保存できます。
- **復習セクション**: 保存したアイテムが一覧表示され、いつでも練習をやり直すことができます。
- **過去添削履歴の閲覧**: 復習セクションでは、練習セクションで生成した過去の回答や添削結果を「過去履歴ボタン」からいつでも確認できます。
- **継続的な学習**: 復習セクションで新たに行った練習内容も、自動的に履歴に追加保存されます。
- **復習特化UI**: 復習セクションでは、デフォルトで答え（英文）を隠した状態からスタートし、自力で思い出すトレーニングに集中できるデザインを採用しました。
- **デザインの統一とニューモーフィズムの徹底**: 復習セクション、履歴、バリエーション生成結果のすべてのUIパーツにおいて、アプリ全体のニューモーフィズム・デザインを完全に統一しました。ボタンサイズや影の質感を揃え、どのセクションでもプレミアムな操作感を提供します。
- **ペルソナフィードバックの保存**: 復習アイテムに保存する際、添削結果だけでなく**ペルソナ（ルイス、エレーナ、ジェームス）からのフィードバック内容も保存**されるようになりました。復習時にも彼らの多角的な視点を確認できます。
- **MySQLによる永続化**: これまでブラウザの `localStorage` に依存していた復習データが、**サーバー上のMySQLデータベースに保存**されるようになりました。ブラウザのキャッシュ削除によるデータ消失の心配がなくなり、複数端末での学習が可能になりました。

## 最近の更新

### 発音練習モード起動時の英訳表示（btn-translate）自動連動
- **操作性の向上**:
  - 発音練習ボタン（`btn-pronounce-toggle`）をONにして発音練習セクションを展開した際、答えである英訳（`btn-translate`）が非表示状態であれば、自動的に英訳表示をON（展開）にする連動処理を追加しました。
  - これにより、特に英訳がデフォルトで非表示になっている復習モード等において、発音練習を行う際にワンタップで英文を見ながら発音できるようになり、スムーズなトレーニングフローを実現しました。

### 発音練習時の対象英文テキスト（pronounce-target-text）非表示化
- **重複表示の排除とUIのクリーンアップ**:
  - 発音練習（録音）セクション内に表示されていた英文テキスト（`.pronounce-target-text`）を削除しました。
  - すでに上部に同じ英文カードが表示されているため、画面上の重複表示を避けてスマートなUIに改善しました。また、録音説明文を「マイクに向かって英文を発音してください。」に変更しました。

### 日本語訳および英訳テキストのアコーディオン開閉アニメーション化と自動スクロール
- **スライドイン・アウトによる表示・非表示の滑らかな遷移**:
  - メッセージカード内の日本語訳（`.japanese`）および英訳（`.english`）テキストの表示・非表示切り替えについて、瞬時の切り替えからアコーディオン形式のスライドイン・アウト（スライドダウン・アップ）アニメーションへ改修しました。
  - アコーディオンの開閉時に要素の高さ・余白・透明度がスムーズにアニメーションし、プレミアムで直感的な操作感を提供します。
  - 練習モード（`btn-practice`）の開始・終了時や、添削結果（フィードバック）表示時、および「もう一度挑戦」ボタン（`btn-retry`）のクリック時にも、英語・日本語テキストの表示・非表示が滑らかなスライドアニメーションで切り替わります。
  - アニメーション動作中（スライド中）もトグルボタンの押し込み状態（`active` クラス）がタイムラグなしで即座に連動します。
  - 音声読み上げ中の単語ハイライト機能とも連携し、テキスト非表示（スライドアップ）の開始と同時にハイライト表示が即座にクリアされるよう、遷移中の状態管理を最適化しました。
- **開閉時の対象アコーディオン上端へのスクロール自動追従**:
  - 日本語訳や英訳のトグルボタン、練習モードの切り替え等によるアコーディオンの開閉アクションの発生時、常にその対象となるアコーディオン要素（会話カード）の上端が画面の最上部（20pxの余白付き）にフィットするようにスムーズに自動スクロールする処理を導入しました。

### 英文の任意の位置をクリックして音声再生を開始・シークする機能の追加
- **単語クリックによる再生位置のシークと音声開始**:
  - 表示されている英文テキスト（メッセージカード内およびグローバルオーディオプレイヤー内）の任意の単語をクリックすると、その単語の発音開始位置に音声を即座にシークして再生（または再開）する機能を実装しました。
  - 音声がまだ一度も再生されていない（音声ファイルが生成・ロードされていない）場合でも、英文内の任意の単語をクリックすることで、自動的に音声の生成・ロードが開始され、ロード完了後にクリックした単語の位置から音声が自動再生されます。
- **UI/UXの改善（ホバーエフェクトの追加）**:
  - クリック可能な英文の単語部分（`.word-highlight-span`）および記号部分（`.word-highlight-symbol`）に `cursor: pointer` スタイルを適用し、ホバー時に薄く背景色をハイライト（記号は下線を表示）させることで、直感的にクリックして操作できるUIを構築しました。

### 日本語訳・英訳トグルボタンのON/OFFに応じたトグルデザインの適用
- **トグル状態（表示ON/OFF）とボタンデザインの連動**:
  - メッセージカードの「日本語訳表示ボタン（`btn-translate-jp`）」および「英訳表示ボタン（`btn-translate`）」について、それぞれの表示・非表示状態（`hidden` クラスの有無）と連動して、ボタン自体に `active` クラスが自動的にトグルされるように改善しました。
  - 通常のトグル動作時に加え、初期ロード（状態復元）時、英訳練習モード（`btn-practice`）の起動時や添削結果の表示時、および再挑戦（`Retry`）を押した際にも表示状態が完全に同期され、ボタンのデザインとテキストの表示状態が常に一致するようになりました。
  - 表示中（ON）のボタンは、インセット影（押し込まれた状態）になり、アイコンと中の文字（「日」・「英」）がプライマリカラー（青）で強調されるプレミアムなトグルデザインを適用しました。

### 失われた改修内容（マージ競合等によるデグレード）の復元とバグ修正
- **自動生成お題のバグ修正とデバッグログ強化**:
  - 自動生成（日本語入力が空の状態）で対話を開始する際、翻訳（translate）モード指定であっても自動的にsituations.jsonからランダムにシチュエーションを選択する処理を復元しました。これにより、入力が空の時にGeminiへの空の翻訳指示が走り、毎回カフェの例文しか出なくなっていた不具合を解消しました。
  - バックエンドでの自動生成開始時に、Geminiへのリクエストプロンプトや詳細な判定プロセスログを `debug_log.txt` に記録する機能も復元し、デバッグの透明性を確保しました。
- **英訳練習モード時の英文テキスト非表示の復元**:
  - 練習モード（`btn-practice`）を有効にして自力で回答を入力している際、答えである英訳テキスト（`.english`）を一時的に画面から隠す処理（`practice-hide-english` クラスの適用およびスタイリング）を完全に復元しました。
  - 回答を確定して添削（フィードバック）結果が表示されたタイミング、あるいは練習モードを終了した時点で英訳テキストを自動的に再表示する制御を適用し、意図しない解答の漏洩を防ぐトレーニング効果を維持します。

### 音声再生プレイヤーにおける英文テキストの非表示化とプログレスバーの拡張
- **英文テキストの非表示化**:
  - 音声再生中にプレイヤー上に読み上げ中の英文が表示されることで答えが分かってしまうのを防ぐため、プレイヤー内の英文表示領域（`.player-info`）を非表示にしました。これにより、リスニングボタン（`btn-initial-listen`）を押した際に、英文を見ずに音だけで内容を判断する「完全なリスニング練習」が可能になります。
- **プログレスバーの拡張**:
  - 英文テキスト領域を非表示にした分、プログレスバー（シークバー）を含む操作領域（`.player-controls`）の横幅をプレイヤー全体の最大幅まで広げ、操作性と視認性を高めました。

### 復習モードおよび英訳練習モードにおける翻訳・トグル表示の不具合修正
- **英訳翻訳表示と練習モード解除の連携バグ修正**:
  - 復習モード（または通常モード）において、英訳練習モード（`btn-practice`）を起動している最中に英訳表示ボタン（`btn-translate`）をクリックした際、練習モードの状態（アクティブボタン状態および表示領域）が確実に解除され、元の英訳テキストが確実に表示されるように挙動を修正・最適化しました。
  - セクション開閉の内部状態が狂っていても確実にボタンのアクティブ状態をクリアし、強制的に閉じられるよう明示的な `classList.remove('active')` と `slideUp` 処理へリファクタリングを行いました。
  - 練習モード中の自力回答時に英訳テキストを非表示にするためのCSSクラス（`practice-hide-english`）がカード要素に残ってしまい、英訳が画面に表示されないデグレードバグを解消しました。また、この練習中断の際、練習タイマーが正しく自動停止（`stopTimer()`）するように修正を行いました。
- **英訳ボタンクリック時の表示崩れ・初期アクション選択肢の完全消去**:
  - 日本語および英語テキストが非表示のときに表示される「初期アクション選択肢ボタン（日本語を英訳 / リスニング）」について、英訳ボタンをクリックした際に初期アクション選択肢ボタンのDOMコンテナが完全に削除されず、画面表示が狂って英訳テキストが非表示のままになる不具合を解消しました。DOMから直接コンテナ要素を検索・除去する堅牢なクリーンアップロジックを実装しました。

### 音声再生時の英文テキストのリアルタイム（視覚的）ハイライト機能の追加
- **カラオケ風リアルタイムハイライト**:
  - グローバルプレイヤーに表示される英文テキスト、およびチャットリスト内の吹き出しに表示されている英文テキストについて、音声再生中に**今どこを読み上げているかを視覚的にわかるようにハイライト表示**する機能を追加しました。
  - テキストを単語単位で分割し、音声全体の再生時間（`duration`）と再生進捗（`currentTime`）から各単語の予測発音タイミングを算出して動的にハイライトします。
  - 単語間スペースのほか、カンマ（`,`）やピリオド（`.`）などの句読点による「一時停止（ウェイト）」を計算に組み込むことで、実際の発話の抑揚やポーズに極めて近いタイミングでハイライトが流れるようにアラインメントを最適化しました。
  - 現在読み上げている単語はプライマリカラー（青）で強調され、背景が薄くハイライトされるとともに僅かにポップアップするアニメーションが適用され、読み終えた単語は若干トーンダウンします。
  - 音声が終了、または停止された際には元のプレーンテキスト表示にシームレスに復元されます（一時停止時は停止した位置のハイライトがそのまま維持されます）。

### グローバルプレイヤーへのABリピート機能の追加
- **ABリピート再生機能**:
  - グローバルオーディオプレイヤーに「AB」ボタンを追加しました。クリックするとA地点とB地点を設定するための「A」「B」ボタンが表示されます。
  - 再生中に「A」ボタンを押すと現在の再生位置がA地点（開始点）として設定され、「B」ボタンを押すとB地点（終了点）として設定されます。
  - 設定された範囲はプログレスバー上に視覚的なマーカーおよび範囲バーとしてハイライトされ、その範囲内でのみシーク・再生されるようになります。範囲外になった場合は自動的にA地点に巻き戻されます。
  - リピート再生（ループ）の継続は、各会話アイテム等に配置されている既存のリピートボタン（ループ再生設定）の状態に依存します。

### 日本語入力からの「忠実な英訳」モードの翻訳精度向上
- **文字数制限の撤廃と忠実な翻訳**:

  - 入力された日本語テキスト全体を一字一句正確に保ち、そのすべてのニュアンスや詳細を含んだ完全な英訳が生成されるようにプロンプトを刷新しました。

### 音声リピート再生時のディレイ（間隔）調整
- **1秒間の間隔（ディレイ）の確保**:

### 英文・和文の両非表示時における初期アクション選択肢ボタンの追加
- **非表示状態での対話的ナビゲーションと再表示機能**:
  - メッセージ生成直後に日本語（和文）と英語（英文）の両方が非表示になっている場合、画面上のメッセージ部分が空白のままになるのを防ぐため、ユーザーが次に行いたいアクションを選択できる2つのボタン（「日本語を英訳」「リスニング」）をメッセージ内容エリア（`.text-content`）に動的に表示するようにしました。
  - アクションボタン（日本語トグル、英語トグル、練習モードなど）を再度操作し、再び画面上のテキストや練習セクションが**すべて非表示になった状態**に戻った場合にも、この選択肢ボタンが自動的に検知して再表示されるように表示制御を改善しました。
- **直感的なショートカット機能**:
  - **日本語を英訳**: クリックすると練習ボタン（`btn-practice`）を自動的に実行し、練習モードを開始します。
  - **リスニング**: クリックすると再生ボタン（`btn-speak`）を自動的に実行し、英文の読み上げを開始します。
- **スマートなUI表示制御**:
  - いずれかの選択肢ボタンをクリックした際、またはユーザーが手動でメッセージフッターのアクションボタン（`btnTranslateJp`, `btnSpeak`, `btnTranslate`, `btnPractice`）を直接操作した際には、選択肢ボタンコンテナは自動的に画面から消去され、進行中の学習画面を邪魔しません。
  - Neumorphism（ニューモーフィズム）のテーマに調和し、各アクションに対応したアクセントカラー（オレンジ・グリーン）が施されたプレミアムなボタンスタイルを導入しました。

### 練習モードでの回答送信後のタイマーおよび入力エリア非表示制御
- **回答送信時のUIクリーンアップ**:
  - 練習モードで英訳の「回答」ボタン（`btn-practice-send`）を押して送信すると、添削中（ローダー）および添削結果の表示に集中できるよう、タイマー（`practice-timer-container`）と入力エリア（`practice-input-area`）が自動的に非表示（`.hidden`）になります。
- **再挑戦・エラー時のUI自動再表示**:

  - 送信処理中に何らかの通信エラーやAPIエラーが発生して添削結果の取得に失敗した場合は、再度回答を入力・送信できるようにタイマーと入力エリアが自動的に再表示され、入力制限も解除されます。
- **UI状態復元時の挙動最適化**:
  - ページ読み込み時にUI状態が復元される際、すでに練習モードの添削結果が表示されている場合は、初期状態でタイマーと入力エリアを非表示にし、添削結果に集中できる表示を維持します。

### 発音改善アドバイスにおける単語ごとの正しい発音確認機能
- **要改善単語の自動リストアップ**:
  - 発音練習後に生成される「発音改善のアドバイス」の下部に、発音が不正確だった単語（発音ミス、聞き取り漏れ、余計な挿入など）を自動的にリストアップします。
  - 各単語には「発音ミス」などのエラーラベルが併記され、どの単語でどのような問題があったかが一目で分かります。
- **正しいお手本発音の即時再生**:
  - リストされた各単語の横に発音再生ボタンが設置されており、クリックするだけでその単語のネイティブスピーカーによる正しい発音（モデル音声）を即時再生します。
  - 再生中にはボタンが neumorphic（へこむ・ハイライト）表示のアクティブ状態になり、再生完了で自動的に元に戻ります。
  - 全体の音声再生機能と同期しており、別の音声が再生された場合は自動的に停止するよう安全に統合されています。

### 練習モードでの「解答時間（確定までの時間）」計測・記録機能
- **解答スピードの自動計測とストップウォッチ演出**:
  - 練習ボタン（`btn-practice`）を押してから、または再挑戦（`Retry`）を押して入力エリアにフォーカスしてから、英訳の「答え確定」ボタンを押すまでの経過時間（秒）を自動計測する機能を追加しました。
  - 練習開始とともに、入力エリアの上部にリアルタイムで秒数がカウントアップされる**ストップウォッチ（練習タイマー）**が表示されます。
  - 時間経過に応じてタイマーのカラーが動的に変化（8秒以上で警告オレンジ、15秒以上で危険赤＋脈動アニメーション）し、ユーザーに「早く答えなければ！」という適度な緊張感を与える視覚的演出を導入しました。
  - 計測された解答時間は、送信時の添削結果および履歴表示部分に「⏱️ 8.5s」のようにバッジで分かりやすく表示されます。
  - すでに添削結果が表示されている状態で練習セクションを一度閉じ、再度開いた場合にはタイマーのカウントアップが誤って再開しないよう制御を改善しました。再度カウントアップが開始されるのは、新しく「再挑戦（Retry）」ボタンを押したタイミングのみとなります。
- **メイン会話（返信時）のヒント使用時タイマーおよび解答時間バッジ表示**:
  - メインチャット画面での返信時においても、ヒント表示内のヒント項目（`hint-item`）をクリックしたタイミングからリアルタイムカウントアップタイマーが開始されるようにしました。
  - タイマーはメイン入力エリアの上部に表示され、練習モードと同様に時間経過によるカラー変化および脈動演出が走ることで、瞬発的に英語を発話する練習をメイン会話でも効果的に行うことができます。メッセージ送信ボタン（`btnSend`）を押したタイミングでタイマーが停止・非表示になります。
  - メイン会話での返信送信後、添削結果内のユーザー解答表示部分に「⏱️ 4.2s」のような解答時間バッジを表示するようにし、返信にかかった時間が一目でわかるようにしました。
  - この経過時間は履歴データ（`retryHistory`）としても保存され、復習モードでも解答スピードを確認可能です。
  - メイン会話返信時には、チャット上の通常の吹き出し（`user-message`）を表示せず、添削結果内のユーザー解答表示（`userInputDisplay`）のみを表示するように最適化しました。これにより、二重表示が解消され、添削内容の直上に英文テキストと解答時間が一元的に確認できるようになりました。
- **履歴への保存と復習モードへの対応**:
  - 計測された解答時間は履歴データとして自動的にサーバー上（MySQL）に保存され、復習モードでも過去の解答スピードを確認できます。どれだけ早く英語を発話・解答できたかの指標として活用できます。

### 練習モードでの発音結果デザイン反映不具合の修正
- **デザインの完全統一**:
  - 通常の練習モードで発声録音した際の発音結果において、単語ごとの点数表示をホバー時のみに制限し、かつ各単語の背景を点数に基づいたプログレスバー風のグラデーションで塗りつぶす新デザインが適用されていなかった問題を修正しました。
  - 音声評価結果を描画する `renderPronunciationResult` 関数が練習セクションのローカルスコープと共通スコープで重複して定義されていたため、ローカルの古い定義を削除して共通の関数宣言に一本化（ホイスティングを利用した共通化）しました。これにより、練習モードと復習モードの双方で完全に同一のデザインロジックが走り、一貫したビジュアルフィードバックが得られるようになりました。
- **録音ボタンのテキスト表示・形状の動的制御**:
  - 非録音時（通常時）の「発声開始」というテキスト表示を不要とし、マイクアイコンのみで表示されるすっきりとした丸型のボタンデザインに変更しました。
  - 録音を開始した際には、ボタンが赤く脈動するアニメーションとともに「録音停止」のテキストがスライド表示され、従来の「録音中 (最長15秒)...」といったステータス表示も維持する形にしました。これにより、無駄なUIスペースの占有を避けつつ、現在の動作状態が一目で理解できるようになりました。
- **自分の録音音声（MP3圧縮）のサーバー永続保存と自動クリーンアップ**:
  - これまでブラウザの一時的なメモリ（Blob URL）にのみ保持され、リロード後に消失していた「自分の声を再生」機能を、サーバーへの自動アップロード・保存によって完全に永続化しました。
  - 発音評価API（`evaluate_pronunciation.php`）の呼び出し時に、Azure Speech APIへの送信自体は高精度のWAV形式で行い、評価完了後の保存用データはサーバー側でLAMEを用いて高品質なMP3形式（モノラル 48kbps）に自動変換・圧縮して `audio/user_recordings/` に保存します。これにより、WAV形式に比べてファイルサイズを約1/10以下に削減し、サーバー容量を大幅に節約します。
  - **自動容量クリーンアップ**: ディスク容量を圧迫しないよう、フォルダ内のユーザー録音音声ファイル（`.mp3`および既存の`.wav`）の合計サイズが 500MB を超過した場合、更新日時の古い順に自動的にファイルを削除する容量制御ロジックを実装しました。
  - **過去履歴・他デバイスからの再生復元**: 保存された音声ファイルパスはお気に入りデータ（Reviewsデータ）に紐づけられ、ページリロード後や他デバイスからのアクセス時でも、過去履歴として「自分の声を再生」ボタンから録音した音声を直接サーバーから読み込んで再生できるようになりました。音声が存在しない場合のみ、安全にグレーアウト無効化状態（ツールチップ付き）になります。

### 外部APIを用いた「発音練習・評価」機能の実装
- **発音評価 (Pronunciation Assessment) の統合**:
  - 各例文カードに「発音練習」ボタン（マイクアイコン）を追加し、マイクを通して自分の英語の発音をリアルタイムに評価できる機能を実装しました。
  - バックエンド (`api/evaluate_pronunciation.php`) から Microsoft Azure Speech Service の発音評定APIを呼び出し、ユーザーの発音を判定します。
  - **総合スコアのビジュアル表示**: 判定結果をニューモーフィズムに調和する滑らかなアニメーションを伴った円形ゲージとパーセンテージで表示します。
  - **細部指標（正確性・流暢さ・完全性）**: それぞれ個別にプログレスバーとして可視化し、発音の何が課題かを細かく分析します。
  - **単語ごとの詳細フィードバック**: 文中のどの単語が正しく発音でき、どの単語が不正確だったか（または発音漏れしていたか）を色分けでハイライト表示し、各単語をホバーするとその単語単体の正確性スコアやエラー種類をツールチップで確認できるインタラクティブなUIを実装しました。
  - **単語ごとの点数常時表示**:
    - ホバーしなくても各単語の正確性スコアが確認できるよう、各単語のすぐ近くに最小サイズ（0.65em）で常時スコアを表示するように改善しました。これにより、どの単語が苦手なのかを瞬時に俯瞰して把握しやすくなりました。
  - **再生ボタンUIの調整**:
    - 発音練習エリアの「自分の発音を再生」および「お手本音声を再生」のボタンデザインを、メインアクションバー（`class="actions"`）の丸型ボタン（`@include neumorphism-icon-btn`）と統一しました。「自分の発音を再生」ボタンには `btn-translate-jp`（円に丸）、「お手本音声を再生」ボタンには `btn-translate`（円に線）のアイコンをそのまま流用し、再生中にはインセット影等のアクティブ表示になるプレミアムな動きを適用しています。
  - **発音練習の添削データの永続化と復元**:
    - ユーザーが発音練習を行った結果（総合スコア、単語ごとの判定、AIのフィードバック詳細アドバイス等）を、復習ブックマーク（保存）時にMySQLデータベースの復習データ（`reviews.content`）に保存・記憶するようにしました。
    - 最新の発音練習の添削結果で前回の履歴を上書き保存する形とし、ページのリロード時や復習タブ切り替え時にも最新の発音添削結果UIが100%復元されます。また、リロード後は自分の録音音声（Blob URL）は消えるため「自分の声を再生」ボタンは非表示とし、お手本音声再生ボタンのみを使用可能にするなど、UX上の整合性を確保しました。
  - **ポータブルなWAV録音**: JavaScriptのWeb Audio APIを活用し、外部ライブラリに依存せず、あらゆるブラウザ環境で動作する「WAV (PCM 16kHz, 16bit, Mono)」のバイナリ生成・送信処理を自前で実装しました。
  - **デモ用モック評価モード**: 環境変数 `.env` に Azure Speech Service の API キーやリージョンが設定されていない場合でも動作を確認できるよう、例文テキストを解析して自動生成される高品質な模擬評価（モックデータ）を返却する安全なフォールバック設計を採用しました。
  - **自分の声とモデル音声の聞き比べ機能**:
    - 各英文の再生ボタン（青）の隣、および発音練習セクション内にそれぞれ「自分の声を再生」ボタン（緑）を追加しました。
    - 発音練習で録音を行った後、このボタンをクリックするだけで、録音した自分の声（WAV）が再生されます。元のモデル音声と交互に再生することで、イントネーションや発音の違いを直接聞き比べ、AIのアドバイスをもとにどう改善すべきかを検証・追求しやすくなりました。
    - 音声再生時にはボタンに連動して `.active`/`.playing` クラスが付与され、再生中はボタンがへこんだ状態になり、再生が終わると自動的に戻るプレミアムなインタラクティブ体験を提供します。

### 音声データ合計1GB制限と自動クリーンアップ機能
- **ストレージ容量制御**: Google Cloud Text-to-Speechで生成された音声キャッシュファイルがディスク容量を圧迫しないよう、合計1GBまでの容量上限を設けました。

- **データベースの拡張と最適化**: スキーマ更新により、`audio_cache` テーブルに `file_size` カラムを追加し、ディスクI/Oを行わずにクエリ上で瞬時に合計容量を計算・制御できる高速な設計を採用しました。

### URLから作成モードのUI/UX向上と履歴機能の追加（MySQL/会員データ同期対応）
- **最後の入力URLの自動保持**: サイトを閉じたりリロードしたりしても、最後に入力して生成されたURLが入力欄に自動的に維持されるように改善しました。
- **ワンタップクリア（x）ボタンの設置**: 入力欄の右端にクリアボタンを追加し、入力されたURLを一発で消去できるようにしました。

  - これまでブラウザの `localStorage` にのみ保存されていたURL履歴を、**MySQLデータベース（`user_url_history`テーブル）に保存する会員永続化**へ移行しました。
  - ログインしているアカウント情報と紐づけてサーバー管理されるため、PCやスマートフォンなど複数端末の間でURL履歴が自動的に同期・共有されます。非ログイン時はローカルストレージを使用する安全なフォールバック設計にしています。

- **履歴の個別削除ボタン（ゴミ箱アイコン）の追加**:
  - 各履歴アイテムの右端に個別の削除ボタンを設置しました。不要な履歴をクリックするだけで簡単にリストから消去（データベースおよび `localStorage` から除外）できます。ホバーすると赤くハイライトされる視認性の高いスタイルを実装しています。
- **履歴アイテムのデザイン崩れ修正**: リスト幅と影の余白（Padding）を調整し、履歴アイテムのボックスシャドウがコンテナ端で途切れてしまう見た目の不具合を解消しました。（その後、より洗練されたフラットなデザインに移行しました）
### 練習モードへの「URLから作成」機能の改善および不具合修正
- **ランダムセグメント切り出しによる重複選定の完全解消**:
  - 同じURLから何度も生成した際に、常に同じ一文（記事の最初の一文など）ばかりが選定される現象を解決しました。
  - バックエンド側（`api/generate_text.php`）で、スクレイピングされた本文テキスト全体から**ランダムな開始位置に基づいて300〜600文字程度の連続する段落（セグメント）を切り出すアルゴリズム**を導入しました。
  - Geminiにはこの切り出された部分テキストのみを提示して一文を抜き出させることで、同じURLを入力しても毎回異なる位置の文章が均等にお題として選定されるよう改善し、重複を構造的に完全に回避しました。また、既出リスト（除外リスト）に含まれる段落をPHP側で事前にフィルタリングするガードも実装しました。
- **一文の途切れ防止と完全性の最優先化 (プロンプトの厳密化)**:
  - 抽出された文章が途中で途切れて不完全な形式にならないよう、目標文字数の指定よりも一文全体の完全性を【絶対最優先】とするようプロンプトの制約を厳密化しました。これにより、文字数制限のために文頭が削られることなく、文頭から文末までの一文全体を正しくコピペ抽出するように強化されました。
  - プロンプト内から不要なノイズワード（具体的なNG会話の例など）を排除し、提示された本文データにない無関係な会話（アパレルの接客会話など）を勝手に創作して出力するハルシネーションを強力に防止しました。
- **重複排除機能とURL混入の修正強化**:
  - フロントエンド（`js/app.js`）およびバックエンド（`api/generate_text.php`）の双方で、除外リスト取得・登録時のURL判定処理を正規表現を用いて強化しました。
  - これにより、URLやゴミデータが除外リスト（`speaking2_recent_situations`）へ絶対に混入しないようにガードし、過去に混入した不要なURLデータも確実にフィルタリング・自動クリーンアップされます。

### iOS PWAログイン永続化＆放置時の画面状態（添削・Q&A結果）維持の実装

  - 安全な32バイトの暗号トークンを用いた永続化トークン（`user_tokens`テーブル）をMySQLデータベースに追加。ログイン成功時にブラウザの`localStorage`へトークンをセキュアに保持し、PWAコールドスタート時にも認証を自動復元する仕組みを構築しました。
- **放置時の画面状態（添削・回答結果）の維持 (Auto State Preservation)**:
  - 回答後や添削結果画面のまま数時間放置した際、メモリ解放でアプリが初期状態（シチュエーション選択画面）に戻るストレスを排除しました。

### 初回添削コメント時の「また挑戦してくれたね」等の表現の改善
- 練習モードでの最初の回答添削時など、初めての英文作成であるにもかかわらず、AIの添削コメントが「また挑戦してくれたね」といった再挑戦（リトライ）を前提としたニュアンスになってしまう問題を修正しました。
- 原因として、練習モード実行時に回答履歴データ（`practiceRetryHistory`）が空であるべき初回送信時に、送信中の未完了データが履歴に含まれて送信されてしまっていたこと、またバックエンド側で履歴が空である場合と履歴がある場合でプロンプトの指示を明確に分ける制御が不足していたことが判明しました。
- 今回の修正により、クライアント側（`js/app.js`）では送信時に現在進行中の未完了データを正しく除外して送信するよう変更し、バックエンド側（`api/correct_text.php`）では履歴が存在する（または明示的な再挑戦である）場合にのみ「前回の添削を踏まえたアドバイス」のプロンプトを注入するよう動的制御を実装しました。これにより、初回は純粋な初回用の添削、再挑戦時は前回の踏襲を踏まえた添削が正確に行われるようになります。

- 単に文法的に正しいだけでなく、実際の現地の日常会話で使われるような、自然で人間味のある（非ロボット的な）表現を優先的に生成・提案するようにプロンプトを最適化しました。
- 添削時の提案（Suggestions）においても、選択したレベルに応じた自然な言い回しが提示されるようにロジックを統合しました。
- バリエーション生成メニューにも「ネイティブ」ボタンを追加し、元の文章をよりこなれた現地風の表現に一クリックで変換できるようになりました。

### UI・デザインの改善
- **保存ボタンの色修正**: 保存ボタン（btn-save）がアクティブな状態（保存済み）のときに緑色になっていた仕様を、他のボタンと同じ青色（$primary-color）に統一しました。これにより、UI全体の一貫性と美しさが向上しました。

### 日本語訳表示・非表示機能の追加
- 練習モードおよび復習モードにおいて、文章の日本語訳を最初非表示にするように変更しました。これにより、日本語の訳を事前に見ずに自力で英訳や会話のトレーニングを行えるようになりました。
- 各会話アイテムのボタンの先頭を「音声再生ボタン」、次に「日本語訳表示/非表示ボタン（日本国旗アイコン）」、その次に「英訳表示/非表示ボタン（アメリカ国旗アイコン）」の順に配置し、それぞれのトグル動作が直感的に分かるようにアイコンデザイン（単色）および並び順を最適化しました。
- 英訳練習モード（btn-practice）を開始した際には、お題となる日本語訳が自動的に表示されるように連携を最適化しました。
- 日本語訳、英文訳を表示した後に一定時間（1分）で自動的に非表示にする制限を廃止し、手動で非表示にするまで表示状態が維持されるように変更しました。

### 音声再生のプログレスバー表示とシーク機能
- 音声再生時に、画面下部に固定されるプレミアムなガラスモーフィズムデザインの「グローバルオーディオプレイヤー」が表示されるようになりました。
- プレイヤーには現在再生中の音声内容（お題の英文、改善単語、自分の録音など）のテキストプレビュー、再生/一時停止ボタン、現在の再生時間 / 総再生時間、およびプログレスバー（シークバー）が表示されます。
- プログレスバーをドラッグまたはクリックすることで、音声の好きな位置からシークして再生することが可能です。
- 音声再生が終了、あるいはプレイヤーを閉じることで、プレイヤーは滑らかにスライドダウンして非表示になります。

### 音声再生とテキストハイライトの同期改善
- 英文の音声再生時に、再生位置に合わせてテキストの色が変わるハイライト機能（カラオケ風表示）において、カンマやピリオド等の記号が再生前後で元の色のまま残ってしまう不具合を修正しました。
- 記号（スペースを除く）も個別にハイライト対象の要素（`word-highlight-symbol` クラス）として抽出・マークアップし、再生進行度に合わせて単語と同様に読み終えた段階で色が薄くなるようにしました。
- 読み上げ中のアクティブ表示時には、記号に余計な余白や拡大・背景色アニメーションを適用させないことで、レイアウト崩れを防ぎつつ自然な視覚的同期を実現しています。

### 発音録音最長時間の動的延長（長文対応）
- 英文の文字数や単語数に応じて、発音の録音最長時間（従来は一律15秒固定）を動的に延長するように変更しました。
- 1単語あたり2秒＋15秒の基本猶予を自動算出し、最小30秒から最大120秒まで最長録音時間を確保します。これにより、長文の読み上げ時でも録音が途中で勝手に終了するのを防ぎます。
- タイムアウト時間の動的化に伴い、録音中のステータス表示を「録音中 (最長15秒)...」から「録音中...」へ変更しました。

### 発音の添削結果に対するQ&A質問機能の追加
- 発音練習後に表示される発音添削結果およびAIアドバイスの下部に、自由に入力して質問ができる「発音Q&Aセクション」を追加しました。
- 特定の単語の正しい発音方法や、イントネーション、AIからのアドバイス内容についてAIコーチへ直接質問できるようになりました。
- 質問履歴は他のQ&A機能と同様に、ブックマーク（お気に入り）時に自動的にサーバーへ永続化され、ページをリロードした際や復習モード時でも履歴が正常に復元されます。
- 発音Q&Aからの質問時は、文法・作文の解説（単語の言い換え提案など）は行わず、母音・子音の口や舌の動かし方、イントネーション、リンキングなど「発音の改善ポイント」のみに回答を制限する厳格なAI指示（プロンプト制約）を導入しました。
